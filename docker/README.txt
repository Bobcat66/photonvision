WPILib Thirdparty GTSAM v2027-4.3-5 was built against TBB v2022.1.0-1+deb13u1, which is the version that ships with Debian 13 (trixie).
If you are building GTSAM from source, you must use this version of TBB, or else you will get a runtime error when trying to load the GTSAM shared library.
